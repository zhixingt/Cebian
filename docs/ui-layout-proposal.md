# ChatInput 布局调整示意

## 当前布局

```
┌─────────────────────────────────────────┐
│  [new-prompt1] [new-prompt2] [new-prompt3] [new-prompt4]  >  │  ← Prompt 快捷按钮（外层）
├─────────────────────────────────────────┤
│  🖱️ ⭕ ▶️ 📷 📎 📱  输入 / 查看命令...       │  ← 工具按钮 + 输入框（内层）
│  DeepSeek V4 Flash  ▼  思考: 中 ▼      [➤]│
└─────────────────────────────────────────┘
         ↑
    问题：Prompt 与输入框距离远，辅助效率低
```

## 建议布局

```
┌─────────────────────────────────────────┐
│  🖱️ ⭕ ▶️ 📷 📎 📱                        │  ← 工具按钮（外层，前置操作）
├─────────────────────────────────────────┤
│  [new-prompt1] [new-prompt2] [new-prompt3] [new-prompt4]  >  │  ← Prompt 按钮（内层，输入辅助）
├─────────────────────────────────────────┤
│  输入 / 查看命令...                       │  ← 输入框
│  DeepSeek V4 Flash  ▼  思考: 中 ▼      [➤]│
└─────────────────────────────────────────┘
         ↑
    优势：Prompt 紧贴输入框，边打边选更顺手
```

## 调整逻辑

| 层级 | 放什么 | 原因 |
|------|--------|------|
| **外层（远离输入框）** | 工具按钮（选择元素/截图/附件等） | 这些是**前置操作**：先选元素/截图，完成后才进入输入。放在外层不干扰打字流。 |
| **内层（紧贴输入框）** | Prompt 快捷按钮 | 这些是**输入辅助**：边打字边点选快捷指令。紧贴输入框减少视线移动，提升效率。 |

## 一句话总结

> **工具按钮是"先操作再输入"，放外层；Prompt 是"边输入边辅助"，放内层。**
