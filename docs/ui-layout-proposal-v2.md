# ChatInput 布局调整示意 V2

## 当前布局（三排）

```
┌─────────────────────────────────────────┐
│  [阅读页面] [截图分析] [操作页面] [填写表单] [监控页面]     │  ← 第一排：页面操作
├─────────────────────────────────────────┤
│  [new-prompt1] [new-prompt2] [new-prompt3] [new-prompt4] > │  ← 第二排：快捷提示词
├─────────────────────────────────────────┤
│  🖱️ ⭕ ▶️ 📷 📎 📱  输入 / 查看命令...       │  ← 第三排：工具按钮 + 输入框
│  DeepSeek V4 Flash  ▼  思考: 中 ▼      [➤]│
└─────────────────────────────────────────┘
```

## 建议布局（两排）：页面操作 + 工具按钮 合并

### 方案 A：工具按钮在前，页面操作在后（推荐）

```
┌─────────────────────────────────────────┐
│  🖱️ ⭕ ▶️ │ [阅读页面] [截图分析] [操作页面] [填写表单] [监控页面]  │
│  选择元素  │                                              │
│  录制等    │  ← 合并为一排，中间可加竖线或留白分隔               │
├─────────────────────────────────────────┤
│  [new-prompt1] [new-prompt2] [new-prompt3] [new-prompt4] > │  ← 快捷提示词
├─────────────────────────────────────────┤
│  输入 / 查看命令...                       │
│  DeepSeek V4 Flash  ▼  思考: 中 ▼      [➤]│
└─────────────────────────────────────────┘
```

**推荐原因**：
- 左侧工具按钮是**高频即时操作**（点一下立即生效）
- 右侧页面操作是**模式切换**（进入某种操作状态）
- 从左到右：即时操作 → 模式切换 → 输入辅助（Prompt）→ 输入框，符合操作流

### 方案 B：页面操作在前，工具按钮在后

```
┌─────────────────────────────────────────┐
│  [阅读页面] [截图分析] [操作页面] [填写表单] [监控页面] │ 🖱️ ⭕ ▶️ │
│                                               │ 选择元素  │
│                                               │ 录制等    │
├─────────────────────────────────────────┤
│  [new-prompt1] [new-prompt2] [new-prompt3] [new-prompt4] > │
├─────────────────────────────────────────┤
│  输入 / 查看命令...                       │
│  DeepSeek V4 Flash  ▼  思考: 中 ▼      [➤]│
└─────────────────────────────────────────┘
```

## 评估

| 维度 | 分析 |
|------|------|
| **空间** | 合并后一排按钮较多，建议支持横向滚动或溢出折叠 |
| **分组** | 建议加视觉分隔（竖线 `\|` 或不同背景色）区分"工具按钮"和"页面操作按钮" |
| **一致性** | 页面操作按钮（文字标签）和工具按钮（图标）风格不同，混排需注意对齐 |
| **可取性** | ✅ 合理。三排变两排，垂直空间更紧凑，用户视线移动减少 |

## 一句话建议

> **方案 A 更好**：工具按钮（🖱️）放左，页面操作（阅读页面/截图分析等）放右，中间用细竖线分隔。理由是"即时操作靠手边，模式切换随后"，从左到右递进。
