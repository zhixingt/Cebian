# ChatInput 布局调整示意 V3（最终方案）

## 当前布局（三排）

```
┌─────────────────────────────────────────┐
│  [阅读页面] [截图分析] [操作页面] [填写表单] [监控页面]     │  ← 第一排：页面操作
├─────────────────────────────────────────┤
│  [new-prompt1] [new-prompt2] [new-prompt3] [new-prompt4] > │  ← 第二排：快捷提示词
├─────────────────────────────────────────┤
│  🖱️ ⭕ ▶️ 📷 📎 📱  输入 / 查看命令...       │  ← 第三排：工具按钮 + 输入框
│  DeepSeek V4 Flash  ▼  思考: 中 ▼      [➤]│
└─────────────────────────────────────────┘
```

## 最终方案（两排）

> **方案 A + Prompt 置顶**：快捷提示词保持最上方，工具按钮与页面操作合并为第二排。

```
┌─────────────────────────────────────────┐
│  [new-prompt1] [new-prompt2] [new-prompt3] [new-prompt4] > │  ← 第一排：快捷提示词（置顶）
├─────────────────────────────────────────┤
│  🖱️ ⭕ ▶️ │ [阅读页面] [截图分析] [操作页面] [填写表单] [监控页面]  │  ← 第二排：工具按钮 + 页面操作（合并）
│  选择元素  │                                              │
│  录制等    │                                              │
├─────────────────────────────────────────┤
│  输入 / 查看命令...                       │  ← 第三排：输入框
│  DeepSeek V4 Flash  ▼  思考: 中 ▼      [➤]│
└─────────────────────────────────────────┘
         ↑
    中间可用细竖线或留白分隔两组按钮
```

## 布局逻辑

| 排数 | 内容 | 定位 | 原因 |
|------|------|------|------|
| **第一排（最上）** | 快捷提示词胶囊 | 全局辅助 | 与输入意图相关，但属于"推荐内容"，放在最上方不干扰操作区 |
| **第二排** | 🖱️ 工具按钮 + 页面操作按钮 | 操作核心区 | 左侧是高频即时工具（点一下就生效），右侧是模式切换（进入某种操作状态），从左到右递进 |
| **第三排** | 输入框 + 模型选择 + 发送 | 核心交互区 | 始终固定在底部，用户视线最终汇聚点 |

## 关键细节

1. **分隔方式**：第二排中间建议加一条细竖线 `│` 或 8px 留白，让图标按钮和文字按钮自然分组
2. **溢出处理**：如果第二排按钮过多，支持横向滚动或右侧出现 `>` 箭头
3. **对齐方式**：图标按钮左对齐，文字按钮紧跟分隔线，整体保持一行

## 一句话总结

> **Prompt 置顶作为全局推荐，工具按钮 + 页面操作合并为操作核心区，输入框始终贴底。**
